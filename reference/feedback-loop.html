Feedback loop

A one-page refresher on the basic model of robot control.

Five quantities

Target r — the desired state.

State x — what is currently happening in the system.

Measurement y — information about the state available to a sensor.

Error e = r − y — the difference between the target and measurement.

Command u — the controller's action on the system.

The simplest controller

u = Kₚ · (r − y)

The error's sign determines the direction of correction. The error magnitude and gain Kₚ determine command strength. Actuator limits are usually added as u = clamp(Kₚe, −uₘₐₓ, uₘₐₓ).

Three questions for any loop

  1. What is the state, and what does the sensor actually measure?
  2. How does the command change the state over time?
  3. Will the system recover after a disturbance, and at what cost?
Do not confuse these: a simulator knows the true state; a real robot almost never does. Noise, delay, and state estimation will later appear between x and y.
