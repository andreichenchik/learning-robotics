F P FᵀPropagates uncertainty already present.
QAdds uncertainty from imperfect motion.

Initialization

P₀ is an evidence-based initial assumption: derive it from placement or localization accuracy, sensor calibration, or the previous estimator's corrected covariance. Use larger variance when the initial state is poorly known.

Expanded covariance

P′pp = Ppp + 2Δt Ppv + Δt² Pvv + Qpp
P′pv = Ppv + Δt Pvv + Qpv
P′vv = Pvv + Qvv

Recursive summary. The filter does not store a cloud or every previous error. The pair (x̂⁺, P⁺) contains what the next prediction needs.
Model boundary. This form is exact for linear dynamics with additive noise. Nonlinear pose motion requires a locally linear approximation or another propagation method.
