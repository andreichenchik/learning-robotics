Состояние и дискретное время

Минимальная модель цикла, который робот действительно исполняет на компьютере.

Состояние

Состояние x — минимальная информация о настоящем, которой вместе с будущими входами достаточно для предсказания будущего модели.

Для точки с командой скорости достаточно позиции. Для свободно движущегося тела обычно нужны позиция и скорость: одинаковая позиция при разных скоростях ведёт к разному будущему.

Один дискретный переход

yₖ = xₖ₋d
eₖ = r − yₖ
uₖ = Kₚeₖ
xₖ₊₁ = xₖ + Δt · uₖ

k — номер шага, Δt — длительность шага, d — задержка измерения в шагах. Команда uₖ удерживается между двумя обновлениями.

Без задержки

eₖ₊₁ = (1 − KₚΔt)eₖ
0 < KₚΔt ≤ 1Подход без перелёта.
1 < KₚΔt < 2Перелёты затухают.
KₚΔt ≥ 2Ошибка не затухает.
При задержке эта простая граница больше не достаточна. Контроллер корректирует прошлое состояние и может продолжать разгон уже после пересечения цели.
