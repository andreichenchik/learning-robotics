# Состояние, дискретное время и задержка

Пользователь понимает, что состояние должно содержать переменные, необходимые для предсказания будущего: катящемуся мячу кроме позиции нужна скорость из-за инерции. Он также распознаёт смену знака ошибки при перелёте, связывает большой шаг времени с чрезмерным изменением состояния и отличает текущее состояние `xₖ` от задержанного измерения `yₖ`, по которому контроллер вычисляет команду.

## Evidence

Ответы на эксперименты и итоговые вопросы урока 0002: знак ошибки меняется после пересечения цели; задержка даёт ошибку относительно прошлого состояния; скорость необходима для прогноза движения; большое `Δt` приводит к перелёту; команда вычисляется из измерения `yₖ`, которое может расходиться с фактическим `xₖ`.

## Implications

Следующий урок может вводить позу `(x, y, θ)` как состояние колёсного робота и строить её дискретное обновление без повторения основ состояния и шага времени.
