Prediction moves uncertainty

A robot's motion model predicts not only where it will be, but also how uncertainty in one state variable spreads into another.

Outcome. You will perform one position–velocity prediction, explain why uncertain velocity creates uncertain position, and distinguish propagated uncertainty from new process noise Q.

1. Start with one concrete robot

At time k, a robot is estimated to be at 0 m, moving at 1 m/s. Position is known fairly well, but velocity is less certain:

x̂ₖ = [ position ] = [ 0 ]
[ velocity ] [ 1 ]

Pₖ = [ 0.01 0 ]
[ 0 0.09 ]

The standard deviations are σp=0.1 m and σv=0.3 m/s. Zero off-diagonal covariance means the initial position and velocity errors have no linear coupling.

2. Predict the mean

For one second of constant-velocity motion:

positionₖ₊₁ = positionₖ + velocityₖ Δt
velocityₖ₊₁ = velocityₖ

In matrix form:

x̂⁻ₖ₊₁ = F x̂⁺ₖ

F = [ 1 Δt ]
[ 0 1 ]

With Δt=1 s, the predicted mean is (1 m, 1 m/s). The superscript minus marks a prediction made before the next measurement.

3. Now predict the covariance

P⁻ₖ₊₁ = F P⁺ₖ Fᵀ + Q

First set Q=0 to isolate what the known motion model does:

P⁻ₖ₊₁ = [ 0.10 0.09 ]
[ 0.09 0.09 ]

Position variance grew from 0.01 to 0.10 m². Why? Possible robots that were slightly faster moved farther; slower ones fell behind. The same velocity error now causes a position error, creating positive position–velocity covariance.

F P FᵀMoves uncertainty already present in the previous estimate through the model.
QAdds fresh uncertainty caused by motion the model cannot predict exactly.
P⁻Summarizes both effects before the next sensor correction.

Primary source: Introduction to Robotics and Perception, 4.2: Moving in 2D introduces the linear motion model xₖ₊₁=Axₖ+Buₖ+wₖ and uses Q for motion-model covariance.

4. Where process noise Q comes from

The model says velocity remains constant. A physical robot may accelerate slightly because of wheel slip, a slope, or imperfect actuation. If the unknown acceleration during one interval has standard deviation σa, its covariance contribution is:

G = [ ½Δt² ] Q = G σa² Gᵀ
[ Δt ]

The same unknown acceleration changes both position and velocity, so Q itself has off-diagonal terms. In practice, engineers estimate noise scales from repeated experiments, actuator specifications, and whether the filter's predictions match observed innovations.

6. Expanded formula for this model

P′pp = Ppp + 2Δt Ppv + Δt² Pvv + Qpp
P′pv = Ppv + Δt Pvv + Qpv
P′vv = Pvv + Qvv

This reveals the mechanism directly: velocity variance Pvv enters future position variance multiplied by Δt², and it creates position–velocity covariance multiplied by Δt.

7. Model boundary

This lesson uses a linear constant-velocity model and Gaussian noise. Real wheel slip can be asymmetric or state-dependent, and robot pose dynamics are nonlinear. The same predict structure remains, but later localization will need local linearization or a different representation.
