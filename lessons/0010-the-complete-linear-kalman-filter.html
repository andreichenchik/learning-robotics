The filter is a loop

Prediction moves the estimate forward. A GPS measurement corrects it. The corrected estimate becomes the starting point for the next prediction.

Outcome. You will execute one complete position–velocity Kalman cycle and explain how a position-only GPS measurement can also correct estimated velocity.

1. Retrieve the trust rule

What does K near 1 mean?

If x̂⁻=10 m, z=12 m, and P⁻=R, where is x̂⁺?

2. Four stages, repeated forever

Corrected belief
x̂⁺ₖ, P⁺ₖ
Predict motion
x̂⁻ₖ₊₁, P⁻ₖ₊₁
Read GPS
zₖ₊₁, R
Correct belief
x̂⁺ₖ₊₁, P⁺ₖ₊₁

The filter is recursive: it does not keep every old state or error. The corrected pair (x̂⁺,P⁺) summarizes what the next prediction needs. If no measurement arrives, the predicted pair simply continues into the next prediction.

The general Bayes filter likewise alternates prediction and measurement phases while carrying only the previous belief. See Introduction to Robotics and Perception, 4.4: Localization.

3. Begin from one corrected belief

At time k, the robot's last corrected state is position 0 m and velocity 1 m/s:

x̂⁺ₖ = 01 P⁺ₖ = 0.04000.09

Use a one-second constant-velocity model. Unknown acceleration has σa=0.2 m/s²:

F = 1101 Q = 0.010.020.020.04

4. Prediction

x̂⁻ₖ₊₁ = F x̂⁺ₖ
P⁻ₖ₊₁ = F P⁺ₖ Fᵀ + Q
x̂⁻ₖ₊₁ = 11 P⁻ₖ₊₁ = 0.140.110.110.13

The robot is predicted at 1 m. Position and velocity errors are now positively coupled: a possibility that moved farther is also likely to be faster.

5. GPS arrives

GPS measures only position, so H=[1 0]. It reports z=1.2 m with R=0.25 m².

H = 10 y = z − Hx̂⁻ = 1.2 − 1.0 = 0.2 m
S = H P⁻ Hᵀ + R = 0.14 + 0.25 = 0.39 m²

S is the expected variance of the innovation: prediction uncertainty and GPS uncertainty both contribute to the disagreement we expect to see.

6. One innovation corrects two variables

K = P⁻HᵀS⁻¹ = 0.3590.282
x̂⁺ = x̂⁻ + Ky = 1.072 m1.056 m/s
P⁺ = (I − KH)P⁻ = 0.0900.0710.0710.099
Why did velocity change? GPS did not measure velocity. But P⁻pv=0.11 says position and velocity errors are related, so the velocity gain is Kv=P⁻pv/S=0.282. If that covariance were zero, Kv would be zero and GPS position would not correct velocity.

8. The complete algorithm

repeat each time step:
x̂⁻ = F x̂⁺
P⁻ = F P⁺ Fᵀ + Q

if measurement z arrives:
y = z − Hx̂⁻
S = HP⁻Hᵀ + R
K = P⁻HᵀS⁻¹
x̂⁺ = x̂⁻ + Ky
P⁺ = (I − KH)P⁻
else:
x̂⁺, P⁺ = x̂⁻, P⁻

That is the complete linear Kalman filter: the prediction from lesson 0008 and the uncertainty-weighted correction from lesson 0009, connected recursively.

9. Model boundary

This filter is exact and minimum-variance under its linear-Gaussian assumptions. A real robot may have nonlinear motion, biased sensors, outliers, or incorrectly tuned Q and R. The next lesson will apply the same predict–correct logic to robot localization and identify what changes for a planar pose.
